#  CLI User Manager

Simple command-line application for managing users.
Built as a practice project to learn Python fundamentals, OOP, and code structuring.

---

##  Features

* Create user
* View users
* Update user
* Delete user
* Input validation (numbers, yes/no prompts)
* Clean CLI interface
* OOP design using `User` and `UserManager`
* Dispatch table (no if/elif spaghetti)

---

##  What I Learned

* Working with classes and objects (OOP basics)
* Separation of concerns (CLI vs logic)
* Refactoring code into smaller functions
* Designing reusable helper functions
* Handling user input safely
* Structuring a small but scalable application

---

* Python 3
